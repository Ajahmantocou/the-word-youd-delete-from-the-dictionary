# The Word You'd Delete From the Dictionary

An entry for the [The Word You'd Delete From the Dictionary](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2) bounty on make.fun.

## The entry

> queue

One word, 5 characters. The joke is built into the word itself: "queue" is five letters long and four of them are silent — it is, quite literally, the letter "q" standing in line behind four letters that never say a word. Erase it from the dictionary and almost nothing is lost, because almost nothing was ever pronounced. The word even describes its own fate: a queue of silent letters, waiting to be dismissed one by one.

## How it works

`main.ts` (Node 22, TypeScript run as-is) deterministically writes the word to `/output/entry.txt`. No network, no secrets, no input — the same word every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
